# Student Internship Tracker

A simple and responsive web application to manage and track internship applications.

## Features

- Add internship applications
- Track application status
- Search applications by company name
- Delete applications
- Dashboard with application statistics
- Save data using browser Local Storage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.

## Project Purpose

This project helps students organize their internship applications
and track their progress in one place.
